# Analysis of Competing Hypotheses (ACH)

Structured analytic technique developed by Richards J. Heuer Jr.

## Steps (Summary)
1. Identify possible hypotheses.
2. List significant evidence and arguments.
3. Prepare a matrix (hypotheses vs evidence) and evaluate diagnosticity.
4. Refine – remove non-diagnostic items.
5. Draw tentative conclusions (favor the hypothesis with least inconsistent evidence).
6. Analyze sensitivity to critical evidence.
7. Report conclusions and remaining uncertainties.

ATLAS-OSINT recommends using ACH when multiple plausible explanations exist for the same set of observations.
