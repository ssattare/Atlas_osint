# Admiralty Code (NATO Intelligence Grading System)

Used in ATLAS-OSINT for source and information evaluation.

## Source Reliability (Letter)
- **A** Completely reliable
- **B** Usually reliable
- **C** Fairly reliable
- **D** Not usually reliable
- **E** Unreliable
- **F** Reliability cannot be judged

## Information Credibility (Number)
- **1** Confirmed by other independent sources
- **2** Probably true
- **3** Possibly true
- **4** Doubtful
- **5** Improbable
- **6** Truth cannot be judged

## Usage Rule
Evaluate source reliability and information credibility separately.
