# Security Policy

## Supported Versions

| Version       | Supported          |
|---------------|--------------------|
| 0.1.0-alpha   | Yes (active development) |

## Reporting a Vulnerability

Please open a private security advisory or contact the maintainers.

## Design Principles

- No hardcoded credentials
- Only passive, public-source collection by default
- Explicit privacy boundaries (see docs/PRIVACY.md)
- No unauthorized access or exploitation features
