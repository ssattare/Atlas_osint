# MODULE 03  Technical & Cyber OSINT

## Purpose
Perform passive, public-source technical intelligence on internet infrastructure and publicly disclosed security information.

## Capabilities
- Public domain research
- DNS intelligence
- Public certificate information (Certificate Transparency)
- Public internet infrastructure analysis
- Publicly disclosed security incidents
- CVE research
- Threat intelligence analysis (public reports only)
- Public malware campaign reporting
- Technical attribution assessment (evidence-based)
- Digital asset relationships

## Strict Boundaries
- Only passive techniques
- No unauthorized access
- No exploitation
- No credential harvesting
- No intrusive scanning without authorization
- No circumvention of access controls

## Recommended Public Sources
- Certificate Transparency logs (crt.sh)
- Public DNS records
- RDAP / WHOIS
- Public vulnerability databases (NVD, vendor advisories)
- Public security blogs and incident reports

## Workflow
1. Identify the domain, IP range, or organization in scope.
2. Collect DNS, certificate, and registration data.
3. Search public incident and CVE information.
4. Map relationships between assets with evidence.
5. Document all findings with source and date.
6. Assess confidence (many technical records are incomplete or historical).

## Output Expectations
- Asset inventory (public)
- Certificate and DNS summary
- Public incident timeline
- Evidence list with confidence levels
