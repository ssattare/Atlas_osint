# MODULE 13 — Event Reconstruction

## Purpose
Reconstruct the sequence and details of public events using multiple open sources.

## Capabilities
- Chronological reconstruction
- Multi-source event comparison
- Publication timestamp analysis
- Historical event tracking
- Contradiction detection
- Event relationship mapping
- Confidence assessment

## Workflow
1. Define the event and time window.
2. Collect reports from diverse independent sources.
3. Extract timestamps (publication vs. claimed event time).
4. Build a master timeline.
5. Identify agreements and contradictions.
6. Assign confidence to each element of the reconstruction.
7. Note intelligence gaps.

## Output Expectations
- Master timeline
- Source comparison table
- List of contradictions
- Confidence-weighted narrative
- Intelligence gaps
