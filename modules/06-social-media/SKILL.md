# MODULE 06  Social Media Intelligence

## Purpose
Analyze publicly available social media content and official accounts.

## Capabilities
- Public account discovery
- Official account verification
- Public content analysis
- Publication timeline reconstruction
- Public statement extraction
- Hashtag analysis
- Public engagement analysis
- Content evolution analysis
- Public narrative identification
- Cross-platform content comparison
- Coordinated public messaging analysis

## Boundaries
- Only public content
- Respect platform access controls
- No private-account access
- No covert monitoring
- No scraping that violates terms of service

## Workflow
1. Identify official or clearly public accounts related to the subject.
2. Collect public posts, statements, and timelines.
3. Analyze narrative and messaging patterns.
4. Cross-reference with other modules (media, corporate, person).
5. Register key statements as Evidence.

## Output Expectations
- List of relevant public accounts with verification status
- Timeline of significant public posts
- Narrative summary
- Evidence records for important statements
