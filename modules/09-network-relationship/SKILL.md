# MODULE 09 — Network & Relationship Analysis

## Purpose
Construct and analyze evidence-based relationship graphs.

## Entities That May Be Linked
- Companies
- Organizations
- Public institutions
- Public figures (in professional context)
- Media organizations
- Public events
- Official partnerships
- Published collaborations
- Corporate ownership structures

## Required Fields for Every Relationship
- Relationship type
- Supporting source(s)
- Evidence date
- Validity period (if known)
- Confidence level

## Rules
- Do not infer personal relationships merely from social-media interactions.
- Every link must have supporting evidence.
- Distinguish direct vs. indirect relationships.
- Record confidence and limitations for each link.

## Workflow
1. Identify seed entities.
2. Collect documented relationships from official and reliable public sources.
3. Create relationship records with full provenance.
4. Visualize or tabulate the graph.
5. Analyze clusters and key nodes.
6. Flag weak or single-source links.

## Output Expectations
- Relationship table or graph description
- Evidence list for each link
- Confidence assessment
- Key insights and intelligence gaps
